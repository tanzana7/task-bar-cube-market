# v0.4 市場機能とデータ範囲

## 正規データと更新

`public/market-usd.json`だけを市場スナップショットの正規データとして扱います。収集処理はSteam Community Marketの`search/render/`にUSD指定で接続し、全ページのAppID・通貨・件数・識別子を検証した後、USDスナップショット、商品別USD履歴、`market-rankings.json`を同一のローカル更新として保存します。

SteamのJPY一覧や為替APIは市場更新の依存先ではありません。JPY表示はブラウザがUSD価格に有効な現在のFrankfurter USD/JPYレートを適用して生成します。期限切れ・取得失敗時はUSD価格を維持し、JPY価格を更新待ちとして表示します。履歴はUSDだけに記録し、JPYグラフも表示時の同じ現行レートから生成します。

`market-jpy.json`はデプロイとの互換性を考慮して当面残しますが、v0.4の画面・市場更新・Actionsでは読まず、書きません。

## 一覧、フィルター、お気に入り

- 商品名検索
- 現在選択中の通貨による最低価格・最高価格フィルター
- 最低出品数
- 価格昇順・降順、名前順、出品数の昇順・降順
- `marketHashName`をキーにしたお気に入り（`localStorage`）とお気に入り限定表示
- フィルターリセット、現在の絞り込み後件数

権利確認前のSteam画面DOM観測とqueryAction subtotalは、確定価格・`priceMinor`・価格履歴・ランキングとは別の参考値です。USDモードでは確認できるUSD表示値を、JPYモードでは有効なFrankfurterレートがある場合に限り換算参考値を、価格順と価格帯フィルターに使います。確定価格と参考価格は選択通貨にそろえて表示値で比較し、通貨が合わない値や円レートがない値は比較対象から外して価格不明と同じく価格順の末尾に置きます。カードと市場注記では画面参考値・価格基準未確認・為替換算を明示し、価格履歴やランキングには混ぜません。
- アイテム種類、出品総数、USD市場の取得時刻、有効な参考為替の概要

出品数に欠損が一つでもある場合、市場概要の総出品数は未取得と表示します。実値の0件と未取得を分けます。価格帯・出品数フィルターは値が欠損した商品を該当条件の結果には含めません。フィルター未指定時はその商品を一覧から除外しません。

## 分類情報

現行の正規データ契約とfixturesが確実に提供する商品属性は、表示名、`marketHashName`、画像URL、最安出品価格、出品数、Steam商品URLです。Steam Marketの検索結果だけでは装備レアリティ、装備ティア、Steamチェストレベルを確実に区別できません。商品名のキーワード推定は行わず、フィルターを未実装のままにします。未分類商品が分類条件によって消える経路はありません。

## 詳細・履歴

商品名を押すと詳細が開き、現在の価格、出品数、USD取得日時、Steam Marketリンク、お気に入りを表示します。履歴ファイルは詳細を開いた時だけ遅延取得します。価格統計は選択期間内に観測した最安出品価格についての最小・最大・始点から終点への変化額・変化率です。中央値は表示しません。直近の価格と出品数も実データ点から表示します。

価格グラフ・出品数グラフは24時間、7日、30日、90日、全期間を共有します。どちらも実際の観測点のみを使用し、出品数を販売数量や取引量とは表現しません。観測間隔が一定とは限らないため、時間足、日足、週足、ローソク足は作りません。日時・値は点のツールチップとキーボード操作で読めます。

移動平均とボリンジャーバンドは20観測点、RSIは20点以上のデータがある場合に限り、初期OFFのチェックボックスで追加できます。計算対象はUSDの最安出品価格系列です。価格系指標はJPY表示時に同じ現在レートで変換し、RSIは無次元なので換算しません。約定価格で計算した指標ではありません。

## 価格変動ランキング

`public/market-rankings.json`は商品履歴全体をブラウザへダウンロードせずにランキングを表示するための小さな集計JSONです。USD更新時に商品ごとに作り直します。変化額・変化率は履歴中の直近観測点と基準時刻付近の実観測点だけから計算します。

- 24時間比較: 基準時刻の前後6時間以内にある観測点が必要
- 7日比較: 基準時刻の前後36時間以内にある観測点が必要
- 上昇・下落それぞれ変化率順に最大20件
- 基準価格0、対象期間の実データ点なし、許容間隔外の商品は対象外

ランキングは観測された最安出品価格の変化であり、販売実績や利益のランキングではありません。生成に失敗した場合はUSD・履歴の更新もコミットしない構成です。

## 板情報・成約履歴

今回のSteamリクエストは追加しません。`search/render/`から現在利用するのは一覧商品の最安出品価格と出品数であり、売買板の注文分布、約定履歴、成約数量をこのデータ契約に追加していません。詳細画面の折りたたみ領域では未取得と示します。価格履歴・統計・ランキングを成約価格や取引量と誤認させません。

Steamworksの公開Web API資料にある`ISteamEconomy/GetMarketPrices`はpublisher API keyを必要とする経路です。公開静的サイト用の追加データとして使用しません。[Steamworks ISteamEconomy API](https://partner.steamgames.com/doc/webapi/ISteamEconomy)

## 安全性と互換性

検索語、商品名、ランキング項目はDOMへ`textContent`で挿入します。URLはHTTPSのSteam Market listingまたはSteam static image hostへ限定します。お気に入り保存が使えない環境でもメモリ内操作で一覧は動作します。

旧USD/JPYの`schemaVersion: 2` JSONは維持し、USD形状は変更しません。履歴のJSON形状もUSDのみの既存バージョンを維持します。追加の集計JSONはversion付きで検証します。フィクスチャ以外のデータを商品として作らず、本番キャッシュは空のままです。
