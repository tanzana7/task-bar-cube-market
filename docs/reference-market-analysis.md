# 参考市場分析の計算条件

分析は公開中の `market-observations.json` を画面読み込み時に直接計算する。別の分析DBや定期書き込みは作らず、正しい新規観測を投入すれば再計算される。比較系列は取得元・通貨・価格基準ごとに分離する。既存の確定USD価格履歴・ランキングへ `strMinSellSubtotal` を混入しない。

中央値は2つのセント額の中間が半セントになる場合、表示の差額と整合するようセント単位に一度だけ丸める。時間間隔が空いた部分の価格や出品数は補間しない。JPY表示中も比較統計の原数値はUSD参考価格で、独立したSteamのJPY価格ではない。

## 同一商品の過去相場からの安値候補

異なる商品間の価格差を買い時の根拠にしない。同じ`market_hash_name`で、取得元・USD通貨・未検証の価格基準が一致する観測だけを時刻順に比較する。最低6回、観測期間24時間以上、最新観測が24時間以内であることを要求する。末尾2観測を除いた過去中央値に対して、末尾の連続2観測がともに20%以上低い場合だけ候補とする。2観測の間隔は6時間以内、相互価格差は25%以内、過去中央値からの低下は80%以下とする。単発の誤記や、古い安値を現時点の買い時と誤認しないための条件であり、投資助言やSteamの確定支払額ではない。

現保存データ191点では候補は0件。条件を満たさない間は「データ蓄積中」と表示する。新しい市場観測JSONが供給されれば、ページ読み込み時に自動再計算する。市場フィードの取得・公開ゲートは従来どおりであり、分析の追加によってSteam自動収集は有効にならない。

ウォッチリストの目標判定と差額は、同じ通貨の価格か有効なFrankfurterレートで換算できる価格だけに表示し、24時間超の観測には到達通知を出さない。新観測の投入経路は`market-feed.yml`の既存設定を使う。定期jobの実行には`TBCM_FEED_ENABLED=true`、供給元の掲載許可を示す記録`TBCM_FEED_RIGHTS_REFERENCE`、および`TBCM_FEED_URL`または明示的に認められたqueryAction用の設定が必要。リポジトリ変数が未設定の間はjobをskipする。変数を設定する行為はValve等による許諾を意味しない。
